# Projets ZeroMQ : Embedding de Texte et Redimensionnement d'Images

## 📖 Description
Ce dépôt contient deux projets distincts basés sur **ZeroMQ**, mettant en œuvre des systèmes distribués pour accomplir des tâches spécifiques :
1. **Embedding de Texte** : Calcul des représentations vectorielles de textes.
2. **Redimensionnement d'Images** : Traitement distribué pour redimensionner des images.
